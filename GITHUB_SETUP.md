# GitHub project

Repository: https://github.com/Canopy10979/Lungitude

The source is on the main branch. Secrets, captured media, patient datasets, databases and model checkpoints are excluded from Git. Copy api/secrets.example.php to api/secrets.php and configure the Google API key locally, or set GOOGLE_PLACES_KEY in the environment.

Clone with Git:

```bat
git clone https://github.com/Canopy10979/Lungitude.git
cd Lungitude
```

Follow README.md for PHP and Python startup. GitHub Pages does not run the PHP/Python backend. Do not upload the private downloadable ZIP, which contains local API configuration.
